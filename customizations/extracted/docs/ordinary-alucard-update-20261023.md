# 普通阿卡多技能调整（2026-10-23）

状态：已按玩家提供的规则更新源码与运行资源。适用于4/4体力普通阿卡多，不影响独立的Boss阿卡多。电脑端与Android暂存资源从同一源码构建；本次不制作安装包。

## 命数

游戏开始时获得2枚命（无上限）。每回合限一次，你使用【杀】造成伤害后，摸一张牌。击杀其他角色后获得1枚命。受到致命伤害时，可以移去1枚命，防止此次伤害。

## 豺狼

你使用【杀】无距离限制，次数上限＋1。每个自己的回合限一次，使用【杀】指定目标后，可以令其中一名目标须使用两张【闪】抵消。

## 死河

限定技，出牌阶段，你可以移去全部命（至少1枚），摸等量的牌。直到你的下回合开始，你不能成为其他角色使用牌的目标，免疫其他角色技能直接造成的伤害、体力流失和体力上限减少；你造成的伤害＋X（X为移去的命数）。

发动后永久激活：每个自己的回合限一次，你以【杀】造成伤害后，可以令受伤角色减少1点体力上限（最低减至2）。

## 实现与验证

- 命数击杀奖励只认由阿卡多完成击杀；致命伤害防止仍可选择不发动。
- 【杀】次数上限加一与距离限制解除均为全局修正；豺狼只在阿卡多自己的回合触发，并在选定本次【杀】的一名现存目标后消耗当回合次数。
- 死河至少需要1枚命；移去全部命后摸相同数量的牌。期间的目标防护与对其他角色技能直接效果的免疫在阿卡多下回合开始时结束；永久技能继续存在。
- 永久效果仅在阿卡多自己的回合内由其使用【杀】造成伤害后发动，目标体力上限大于2时可选择降低1点；同一回合限一次。
