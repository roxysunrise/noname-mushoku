## 复现

```powershell
./build-crossover.ps1
node --test crossover.test.mjs online-room.test.mjs boss-roxy.test.mjs expansion.test.mjs online-modes.test.mjs online-skill-callbacks.test.mjs ai-characters.test.mjs
node preview-server.mjs game/resources/app 8092
```

在另一终端使用开发版Electron依次运行 `tools/online-skill-smoke.cjs`、`tools/mobile-ui-smoke.cjs`、`tools/online-modes-smoke.cjs --test-mode=doudizhu`、`--test-mode=versus`、`--test-mode=boss --test-boss=boss_mt_roxy`、`--test-mode=boss --test-boss=boss_alucard`。模式测试独占18080端口，不并发运行。截图输出可用 `NONAME_QA_OUTPUT` 指定，默认 `output/qa`；预览脚本为 `tools/roster-preview.cjs`。

已有游戏进程应在当前对局结束后重启。不要把测试脚本传给已打包的 `game/noname.exe`，应使用开发Electron运行。
