## 模块边界及依赖

| 模块 | 唯一主责 | 依赖与交接 |
|---|---|---|
| UI设计 | 布局、交互、样式、适配及本模块实现验证 | 文案/机制依赖对应模块确认稿；下载/门禁依赖上传云端接口；同步需求交主对话 |
| 上传云端 | 打包、发行版本、腾讯云、校验、恢复、兼容门禁、授权源码推送 | 依赖各模块已验收候选；更新UI依赖UI设计；不发明对局同步逻辑 |
| 角色设计 | 角色机制、完整规则文本、结算意图和平衡草案 | 依赖主对话确认；实现交角色添加删除；不写角色数据或代码 |
| 角色添加删除 | 根据确认稿增删角色、技能代码、数据、资源及本地构建同步 | 依赖角色设计确认稿；公共删除影响交主对话；发行交上传云端 |
| Bug维修 | 复现、定位、已授权最小修复、回归 | 依据原有确认行为修复；涉及其他模块影响只交说明与建议，由主对话明确分配后执行 |
| 功能模式增加 | 新功能/模式规则、流程及本模块实现集成 | 规则依赖主对话确认；UI、角色、发布分别交对应模块；同步需求先上报，获主对话分配后仅实施本模块接点 |

同一文件不自动归某模块永久所有；按主对话明确的变更范围分配。本轮修复若由Bug维修负责，同一变更不得由其他模块并行编辑。删除角色的局部注册属于角色添加删除；公共同步协议、跨模式规则与共用UI变更只输出“影响说明+建议”。
