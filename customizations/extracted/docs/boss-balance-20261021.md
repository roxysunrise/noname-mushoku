# Boss技能定稿（2026-10-21）

用户在审核技能后确认“阿卡多就这样”“洛琪希也可添加”。本次仅实现这两套定稿，不生成新的电脑版ZIP或手机版APK。修改游戏运行目录后，重新加载或重启本地游戏可读取新规则；已经开始的对局应重新开局。已有独立安装包不会自动变化。

## 阿卡多

幻、男、Boss专属、1/1体力；初始2枚嗜血，上限4枚。

- 不灭躯：免疫体力流失和非杀伤害，普通及属性杀均可造成伤害。
- 无生之王：每回合首次使用杀对其他角色造成实际伤害后获得1枚嗜血；同一张杀命中多人共回补一次。可消耗1枚抵消一次杀的全部伤害。每局一次防止致命伤害并获得1枚嗜血。首次有其他角色阵亡后杀伤害永久+1，不叠加。取消准备阶段回补。
- 蚀血侵蚀：自己的回合内，对每名其他角色限一次；造成实际伤害后削减其1点体力上限，不能以此降至2以下。实际削减后自身增加1点上限，至多增加至5。每个自己的回合首次成功削减后回复1点体力。不禁桃，不因死河翻倍。
- 暗影夜宴：其他角色无防具时不能使用任何锦囊，包含普通、延时与转化锦囊。装备防具后即时恢复，失去防具后即时受限。已有延时锦囊正常结算。Boss自身不受影响；Boss离场或失去此技能后限制解除。此版取代原消耗嗜血取消锦囊的方案。
- 黑犬双枪：出牌阶段限一次，杀可额外指定一名合法目标；嗜血至少2枚时可消耗1枚令其中一名目标不能响应。该杀造成伤害后，自身体力上限至少4时可获得受伤目标一张手牌，每次发动合计至多一张。
- 死河零式：第3轮起，限定技；清空嗜血，对其余所有角色各造成1伤害，本回合杀无距离限制、次数上限+2。此后任何途径都不能获得嗜血。尚未使用的致命保护仍有效，但不再给予嗜血。

## Boss洛琪希

保持10/10体力、初始4魔力、魔力上限8。

- 水咏：每轮开始+3魔力；每回合首次普通锦囊结算后+1魔力。
- 水幕：新增；每轮一次，受到至少2伤害时可花2魔力，将本次伤害减1。
- 水袭：出牌阶段两次（决意后三次），每阶段每个目标限一次；花2魔力、弃一张黑色手牌，目标弃两张手牌或受1伤害。
- 水灵：出牌阶段两次，花2魔力回复1体力并摸1牌。
- 豪雨：结束阶段可花3魔力吟唱至下回合开始；期间累计4点实际伤害中断，摸2牌、返还1魔力。完成后其他角色依座次各选择弃两张牌（手牌或装备），否则受1伤害（决意后2伤害）。
- 决意：每局一次，体力降至5或以下时回复2体力并获得2魔力，随后水袭次数改为三次、豪雨伤害改为2。
