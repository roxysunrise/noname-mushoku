# 阿卡多削弱与约翰完美犯罪调整

版本：2026-10-22。本次规则来自用户明确要求，已修改源码并同步当前本地运行目录。云端发布未执行；自动检查与引擎检查不代表实战平衡已验证。

## 阿卡多：仅修改三处

适用于 Boss 阿卡多（`boss_alucard`），不修改普通阿卡多。

### 嗜血

上限3枚。可以消耗1枚，抵消1点【杀】伤害。死河零式释放后永久不能再获得。

初始2枚保持。一次受到多点【杀】伤害时，发动一次只消耗1枚并减少1点伤害，不会抵消整次伤害，也不会自动连续消耗多枚。普通杀、火杀、雷杀均适用。每局一次的致命伤害保护继续独立结算。

### 蚀血侵蚀

锁定技，每个自己的回合限一次，你对其他角色造成伤害后，令其体力上限减少1（不能以此减至2以下）。若实际减少，你回复1点体力。

原先按每名目标分别计算，现改为该回合所有目标合计一次；不再增加自己的体力上限。保留目标体力上限最低2、成功削减后回复1点体力。造成0伤害、对自己造成伤害、对已离场角色或体力上限不大于2的角色造成伤害，不消耗本次触发机会；若技能已发动但削减被防止，则消耗次数且不回复体力。死河造成的伤害同样受这个回合总次数限制。

### 暗影夜宴

锁定技，其他角色没有装备防具时，每回合只能使用一张锦囊牌（含普通锦囊、延时锦囊及转化锦囊；判定区已有延时锦囊正常结算）。

沿用原技能的“其他角色”范围。每回合按使用记录合计，普通、延时及转化锦囊共用额度；任何角色的新回合开始时刷新。装备防具时解除限制，失去防具后按该回合已有使用记录判断，不额外返还次数。

不灭躯、黑犬双枪、死河零式及本次未指定的其他规则保持原实现。双枪原有体力上限至少4的夺牌条件也保留，没有因侵蚀移除成长而额外下调。

## 约翰：完美犯罪

出牌阶段限一次，你可以选择一名其他角色，直到你的下个回合开始时，防止该角色对你造成的所有伤害。你受到伤害后，伤害来源弃置一张牌。

删除原“每回合首次受到伤害时防止之”的被动部分。选定来源的普通、火焰和雷电伤害均可反复防止；未选来源、无来源伤害和体力流失不受该保护影响。来源仍在场且有手牌或装备牌时，受伤后强制弃置1张手牌或装备牌。

保护经过其他角色回合仍然有效，在约翰下个回合开始时清除标记及目标记录。若同一回合另获出牌阶段并再次发动，新目标替换上次目标，始终只保护针对一名来源的伤害。
