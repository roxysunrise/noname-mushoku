# Boss补给与强度调整（2026-10-21）

此记录更新此前 boss-balance-20261021.md 中的对应规则。

- 通用：当前及以后加入 bossRoster 的 Boss 自动拥有「Boss补给」：摸牌阶段基础摸3张、手牌上限+2。其他技能增减摸牌数仍正常叠加；固定摸牌数不受影响。开局发牌不变。
- 阿卡多：初始体力及上限由1/1改为3/3。「无生之王」增加：摸牌阶段基础摸牌数等于体力上限，至少3张。蚀血将上限提高到4/5时，基础摸牌同步提高到4/5；按上限而非当前体力计算。原有嗜血、致命保护、侵蚀上限和死河代价保留。
- 洛琪希：保持10/10。「水袭」魔力消耗由2降为1，仍弃置一张黑色手牌、每阶段两次（决意后三次）、每名目标限一次。对目标造成2点伤害，目标可弃置两张手牌将伤害减为1点。每轮3魔力现在可支持两次水袭并留下1魔力，避免输出与治疗、豪雨同时过度争抢资源。
