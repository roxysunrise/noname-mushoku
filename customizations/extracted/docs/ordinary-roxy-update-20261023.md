# 普通洛琪希技能更新（2026-10-23）

状态：按用户本次修改指令实现并通过下列验证；未打包、未发布。3体力、二次元类、幻势力；仅替换普通角色 `mt_roxy` 的技能，不修改独立Boss版本。

## 用户技能原文

**洛琪希｜二次元类｜幻势力｜3体力**

**水咏**

锁定技，游戏开始时获得2点魔力（上限6）。每轮开始时获得2点魔力。每回合限一次，你使用普通锦囊牌结算结束后，获得1点魔力并摸一张牌。

**水袭**

出牌阶段限两次，每名角色限选一次。你可以消耗1点魔力并弃置一张黑色手牌，对一名其他角色造成2点伤害；其可以弃置至多两张手牌，每弃置一张，此伤害－1。

**水灵**

出牌阶段限一次，你可以消耗2点魔力，回复1点体力并摸一张牌。

**豪雨**

限定技，结束阶段，你可以消耗4点魔力开始吟唱。下个回合开始时，对所有其他角色各造成1点雷电伤害。吟唱期间，你累计受到至少2点伤害时，吟唱中断，你摸两张牌。

## 结算说明

- 不叠加旧研习、水术、授业；新增普通角色独立技能ID，与Boss技能分离。
- 魔力上限6仅限制魔力增加，不阻止水咏的摸牌。普通锦囊不包含延时锦囊；按每个角色回合一次的引擎技能次数规则处理。
- 水袭的目标限制在本次出牌阶段结束后清除；目标可拒绝弃牌而受到2点伤害，弃一张手牌则受到1点，弃两张则不产生伤害事件。装备牌不用于抵消。
- 水灵满体力时仍可发动，无法实际回复不取消摸牌。
- 豪雨消耗4魔力且占用限定次数，不论中断与否均不返还魔力或限定次数。独立吟唱状态在限定技能觉醒失效后继续工作；成功释放前先清除吟唱，避免结算中重复释放。
- 豪雨按实际伤害值累计；体力流失、减上限及被防止的伤害不计入。累计1+1、单次2及单次超过2均中断并仅摸两张。成功时依次对所有其他在场角色造成1点雷电伤害，正常参与属性伤害与受伤技能结算。
