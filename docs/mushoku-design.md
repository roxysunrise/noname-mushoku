# 无职转生角色包 v0.2：花色与锦囊

2026-10-20。现有八人使用各自原创技能，不使用原角色机械数据或幻映形态。本版根据用户要求，参考原版技能的交互方式，增加花色、锦囊和装备参与，减少直接增伤、强制扣血和额外摸牌。禁止重复，人数或规则不满足的玩法暂时禁用，详见 mode-compatibility.md。仅修改源码，不打包。平衡为待试玩的设计假设，不是已验证结论。人物包含剧情信息。

洛琪希在自己的结束阶段，按本回合锦囊使用顺序，自动研习第一种尚未掌握的花色；延时锦囊也计入，无花色不计。重复花色不成长，同回合使用多种花色也只学一种，最快第4个自己的回合结束集齐。研习2时可将红色手牌当顺手牵羊，研习4时可使用装备区素材；不增加伤害、摸牌或手牌上限。水术转化的锦囊也能提供研习花色；顺手牵羊仍受距离限制。此成长表示拓展运用手段，不将原作已成名的老师写成零基础，也不虚构无限魔力或无咏唱。水术仅借用锦囊表达牵制和控制，并非声称原作法术具有这些规则。

龙神普通身份只有3次转无懈的资源，且须消耗一张锦囊手牌；主公每准备阶段可回补1，形成持续反制。无懈可击可以保护自己或其他角色，也可参与反无懈，遵循原引擎结算。不会按忠反身份分配资源。主公强化不额外加体力；身份模式原有主公体力规则仍由引擎处理。

## 原版技能参考与复杂度

- 无咏、水术、三流借鉴国色、奇袭等“特定素材当另一张牌”的方式，直接使用真实锦囊，不手写火攻、顺手或决斗结算。
- 预见、烈剑参考看破的花色资源取舍和铁骑的响应限制；限定同花色且每回合限一次，不附加失去技能、增伤等多层效果。
- 治愈参考急救的转桃方式，改为红桃且每回合限一次；与守护争用同一花色，玩家在救援和提前保护之间取舍。
- 第三眼参考观星，仅处理两张；护幼借鉴反馈的受伤取牌交互，改为替他人争取补偿，不额外创造牌。
- 剑王借鉴猛进的装备争夺主题，调整为单目标杀指定目标后拆装备，不增加伤害；授剑给出的装备可与决意联动。

参考不等于照搬，也不加载原版角色或其技能。转化牌沿用原有目标、距离、无懈和响应规则；动态转化检查当前牌堆是否启用对应牌，并通过原事件的牌过滤器。每人通常两个核心技能，只有洛琪希增加一个限定师徒羁绊；不引入连环技能树。

## 羁绊

仅三组：洛琪希—鲁迪乌斯授业、保罗—鲁迪乌斯救援加摸、基列奴—艾莉丝授剑。授剑交出的装备进入艾莉丝手牌，不自动装备；既能保留装备功能，也可供决意消耗。只判断公开角色名；玩家自行决定是否帮助，不读取隐藏身份，不把同作品角色视为固定队友。保留每局一次与支出/受益上限，不实现婚姻必定结盟或死亡连锁惩罚。

## 接入与验证

角色目录 apps/core/character/mushoku，game/package.js 注册发现，game/config.json 默认启用；旧存档一次性迁移启用，迁移完成后尊重手动关闭。构建脚本按目录自动发现该包。旧角色清理脚本跳过 mushoku，避免误清新内容。

自动验证：node --test tests/mushoku.test.mjs。覆盖角色与技能完整性、四花色成长与重复限制、水术解锁、禁牌过滤、同花色代价、龙力消耗、主公限制、救援、羁绊限次及取牌转交。为技能函数隔离执行测试，不等同引擎事件调度或真实对局验收。联机协议标识升级为 mushoku-eight-sakura-2，避免旧技能客户端加入新房间。

后续验收：八人身份局中轮换龙神主公与非主公，记录存活轮数、洛琪希达到2/4研习的比例、龙力耗尽速度、各角色净牌差与胜率。重点检查火攻展示/弃牌、铁索与属性伤害、顺手距离、无懈链、红桃转桃濒死救援、破坏防具后的杀结算、护幼取牌时的失牌触发，以及联机端的成长花色同步。至少多轮不同身份和座次后再调整；目前不宣称强度已经平衡。
