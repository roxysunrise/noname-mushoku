# 八人角色池与玩法限制

2026-10-20 用户最终确认：所有模式只使用现有八名角色及其现有技能；禁止重复上场，人数或规则不满足的玩法暂时禁用。此决定取代此前的原角色机械槽位、幻映形态兼容方案。

## 角色与技能

只注册鲁迪乌斯、洛琪希、希露菲、艾莉丝、奥尔斯帝德、瑞杰路德、保罗、基列奴。角色体力、性别、幻阵容、头像和 mt_ 技能均来自 character/mushoku/character.js。无别名槽位、幻映形态、原角色包或旧角色分组；扩展载入后再次统一角色池。原版技能代码仍可作为卡牌和规则的依赖存在，但不会作为原武将的技能组合注册到可用角色。

## 开放范围

- 标准身份局：2 至 8 人，需有足够未被禁用的独立角色；双将需要人数乘二不超过实际可用角色数。
- 休闲斗地主：3 人，单将需 3 名、双将需 6 名独立角色。地主加血、飞扬/跋扈等统一模式规则保留，它们不是额外武将或新角色形态。
- 欢乐 2 对 2：需 4 名独立角色，不开放替补或代替队友选将（原分配可能重复）。
- Sakura Frp 联机：仅标准身份局，2 至 8 人；双将、禁将按实际八人池检查。详见 sakura-online.md。本轮仅修改源码，旧 exe 不含此功能。

## 暂时禁用

国战依赖多阵营双将；挑战依赖专属 Boss 与阶段技能；炉石依赖职业及随从；塔防依赖机关与增援；单挑依赖更大的选将替补池；战棋依赖专属单位及可变替补；乱斗含固定角色和随机技能。这些玩法及未验证的扩展模式不会执行 init、startBefore 或选将流程，入口显示具体原因，并提供返回标准身份局的按钮。其他身份、斗地主、对决子模式同样暂时禁用。联机仅开放标准身份局，不开放原版公共大厅。

禁止通过恢复原角色、复制角色或借用原武将技能来规避限制。禁将使可用角色不足时也会拦截，不擅自解除禁将。角色包停用后不会恢复其他角色。
